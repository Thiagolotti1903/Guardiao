## Objetivo do software
O Guardião é um sistema desktop desenvolvido para auxiliar no registro e gerenciamento de ocorrências e atendimentos, permitindo organizar as informações de forma prática e centralizada.

## Funcionalidades do sistema
- Login de usuários.
- Cadastro e gerenciamento de usuários.
- Registro de ocorrências.
- Consulta e gerenciamento de ocorrências.
- Registro de atendimentos.
- Consulta e gerenciamento de atendimentos.
- Armazenamento das informações em banco de dados.
- Interface gráfica para utilização das funcionalidades do sistema.
